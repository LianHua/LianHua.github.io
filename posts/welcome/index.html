你好，世界 👋

这是使用 Hugo Extended + Stack 魔改版 + Decap CMS 搭建的博客示例文章。

你可以通过站点根路径 `/admin/` 使用 Decap CMS，在浏览器里直接撰写、编辑并发布文章，无需本地环境。

代码块

# 本地预览（草稿也会显示）
hugo server -D

# 生成静态文件到 public/
hugo --minify
